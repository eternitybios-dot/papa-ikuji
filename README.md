# パパ育児ガイド

家族で育児を分担するための、スマートフォン向け静的サイトです。
ビルド・外部ライブラリは不要。GitHub Pagesの公開元を main / docs に設定して利用できます。

## 構成

- docs/index.html: 育児コンテンツと画面
- docs/styles.css: 表示・アクセシビリティ
- docs/core.js: 日付計算・保存の共通処理
- docs/app.js: ページ切り替え、チェックリスト、月齢表示
- tests/: Node.js標準テスト

## 開発・確認

Node.js 22以上で `node --test tests/*.test.cjs` を実行します。
ローカル確認は `python3 -m http.server 8000 --directory docs` で配信してブラウザで開きます。
日付は端末のローカル時間で判定。月末生まれの月齢表示は、対象月に同日がなければ末日を記念日とします（法的年齢や投薬判断には使用しません）。

## 保存とプライバシー

誕生日・予定日・チェック状況はブラウザのlocalStorageのみを使用します。
既存のv1保存キーを継続使用します。ブラウザのサイトデータを削除すると記録は消えます。
保存が拒否された場合は画面に通知し、開いている間だけメモリに保持します。端末間同期はありません。

## 医療・制度情報の保守

医療者による監修済みではなく、診断や受診判断の代用にはできません。
電話番号・受付時間・健診・給付制度を変更するときは発行元の資料を確認し、本文付近にリンク・確認日を記録してください。
今回確認できた安全資料: Red Nose Safe Wrapping for Parents（2026-09-20）。
中毒110番の受付時間は今回公式ページを取得できなかったため、未検証の時間を掲載せず公式案内へ誘導しています。
既存の心肺蘇生、予防接種、育休給付等を全面的に再監修した版ではありません。公開前の専門家レビューを推奨します。
